# 右クリックで日本語に翻訳

ブラウザ（Brave / Chrome / Edge）で、**右クリックだけ**で、ページ全体や選んだ文章を日本語に翻訳する拡張機能です。
翻訳には、次のどちらかを選べます。

- **Gemini API の無料枠**（Google の APIキー。追加料金はかかりません）
- **ChatGPT のプラン**（Plus / Pro など、ご契約の利用枠。APIキーは不要で、ChatGPT アカウントでサインインします）

両方を準備して**併用**もできます。たとえば「通常は Gemini の無料枠、使い切ったら ChatGPT」のように、使えないときだけ自動で切り替わります（設定でオンにしたときだけ。既定はオフ）。ページ右下の枠には、実際に翻訳した**モデル名**が表示されます。

## できること

| 操作 | 結果 |
| --- | --- |
| ページ上で右クリック →「このページを日本語に翻訳 / 元に戻す」 | 画面に見えている部分から順に日本語になる。もう一度選ぶと原文に戻る |
| 文字列を選択して右クリック →「選択範囲を日本語に翻訳」 | 選択した場所の近くに訳文が出る（コピーできる） |
| ツールバーの拡張機能アイコンをクリック | ページ翻訳の開始・解除 |

## 入れ方（約 10 分）

1. 上の表の zip をダウンロードして、展開します。**消さない場所**（例: ドキュメント）に置いてください。
2. ブラウザで `brave://extensions` を開きます（Chrome は `chrome://extensions`、Edge は `edge://extensions`）。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダの中の **`extension` フォルダ**を選びます。
5. 開いた設定画面で、注意事項を読んで「上記を理解しました」にチェックを入れます。
6. 「使う AI」を選んで、準備します。
   - **Gemini API**: **ご自身の APIキー**を入力して、「保存して接続テスト」を押します。APIキーは <https://aistudio.google.com/apikey> で、Google アカウントから**無料**で作れます。
   - **ChatGPT のプラン**: 「ChatGPT でサインイン」を押し、開いた OpenAI の画面でログインして承認します。自動で設定画面に戻ったら、「保存して接続テスト」を押します。
7. 緑色で「成功しました」と日本語の訳文が出れば、準備完了です。

詳しい説明（使い方・安全性・困ったとき・仕組み）は、zip に入っている **`manual.html`** をブラウザで開いてください。

## 守ってほしいこと

- **鍵は、ご自身のものを使い、他の人に見せない・貸さない**でください（Gemini の APIキー、ChatGPT のサインイン）。チャット・メール・画面共有・スクリーンショットに載せないでください。
- Gemini を使う場合、Google 側で、**支払い方法（請求先）を登録しない**でください。登録しなければ、有料プランにはなりません。
- **メール・社内文書・個人情報や機密情報のあるページでは使わない**でください。翻訳する文章は Google または OpenAI に送られます。
- 共用のパソコンでは、設定画面で「このパソコンにキー・サインイン情報を保存しておく」を**オフ**にしてください（ブラウザを閉じると忘れます）。ChatGPT は、使い終わったらサインアウトします。
- 「併用」をオンにすると、主の AI が使えないときに、**もう一方の会社にも**文章が送られます。

## ダウンロードしたファイルの確認（おすすめ）

ファイルが改ざんされていないか、PowerShell で確かめられます。zip を置いたフォルダで実行してください。

```powershell
Get-FileHash .\{{ZIP_NAME}} -Algorithm SHA256
```

表示された値が、上の表の SHA-256 と **1 文字も違わず**一致すれば問題ありません。違うときは、使わずに配布者へ連絡してください。
（より確実にするため、配布者から**別の方法**でも SHA-256 を受け取って照合してください。）

## Google・OpenAI の利用規約についての注意

### Gemini API を使う場合

Google の「Gemini API 追加利用規約」（<https://ai.google.dev/gemini-api/terms>）には、次のような記載があります。**ご自身でも原文を確認してください。**

- **EEA（欧州経済領域）・スイス・英国**では、API クライアントを提供する場合、有料サービスのみを使うこととされています。無料枠を前提とするこの拡張機能は、これらの地域の方には**使えない可能性**があります。
- Gemini API は **18 歳以上**が対象です。
- Google AI Studio と Gemini API は、開発者が業務目的で使うことを想定しており、一般消費者としての利用は想定外とされています。
- 無料枠では、送った内容が Google の製品改善に使われ、**人間の担当者が内容を確認する場合があります**。

### ChatGPT のプランを使う場合

OpenAI の「Sign in with ChatGPT」（<https://developers.openai.com/siwc>）の公式の手順に沿って実装しています。ただし、公式ドキュメントは**ブラウザの拡張機能での利用には触れていません**（許可も禁止も書かれていません）。ご自身でも原文と OpenAI の規約を確認してください。

- 翻訳に使った分は、ご契約のプランの**利用枠から差し引かれます**（ChatGPT 本体や Codex など、同じプランの他の使い方と分け合います）。
- 送った内容の扱いは、OpenAI の規約とご契約のプランの設定によります。
- OpenAI 側の仕様変更で、**使えなくなる可能性**があります。そのときは、Gemini API に切り替えてお使いください。

規約は変更されることがあります。配布者は、これらの規約への適合を保証しません。

## 安全性とプライバシー（要点）

| 項目 | 内容 |
| --- | --- |
| 送信されるもの | 翻訳する文章（ページ上の文字・タブのタイトル・選択した文字）、文脈の参考（翻訳する部分の直前の見出し・文章。訳さない）、鍵（Gemini の APIキー、または ChatGPT のサインインで得たトークン）。送信先は、選んだ AI の会社（Google の Gemini、または OpenAI）だけ |
| 送信されないもの | ページの URL、Cookie やログイン情報、入力欄の中身、閲覧履歴、ChatGPT のパスワード（OpenAI の画面にだけ入力します） |
| 保存されるもの | APIキー・サインイン情報・設定・翻訳結果のキャッシュ（このブラウザの中だけ。暗号化はされません） |
| 権限 | 右クリックメニュー、操作したタブへの一時的なアクセス、設定の保存、Gemini・OpenAI への通信、サインインの戻り先（自分のパソコン内のアドレス 1 つ）の観測のみ |
| 動作するとき | 右クリックメニューかアイコンを押したタブでだけ動く。常時の監視はしない |
| 安全装置 | 通信先を Gemini・OpenAI に固定。短時間の大量送信を自動で止める。エラー表示では鍵を伏せ字にする |

これらは配布者による**自己検証**で、第三者の監査ではありません。パソコン自体がウイルスに感染している場合などは、鍵を守りきれません。

## 更新するとき

自動では更新されません。新しい zip を受け取ったら、次のどちらかで入れ替えます。

- **同じフォルダに上書き**（おすすめ）: 新しい zip の `extension` フォルダの中身を、今使っているフォルダに上書きコピーし、`brave://extensions` で「再読み込み」を押します。設定はそのまま引き継がれます。
- **入れ直す**: 古い拡張機能を「削除」して、新しいフォルダを読み込みます。この場合、設定とキー・サインインは消えるので、再入力・再サインインします。

## やめるとき

1. 設定画面の「**APIキーを削除**」（Gemini）、または「**サインアウト**」（ChatGPT）を押します。
2. `brave://extensions` で、この拡張機能を「削除」します。
3. 念のため、Google AI Studio の APIキーのページで**キー自体も削除**します。ChatGPT は、ChatGPT の設定にある接続（連携）の管理から、この拡張機能の接続を解除します（これが最も確実です）。

## 困ったとき

zip に入っている `manual.html` の「困ったとき」に、症状別の対処をまとめています。よくあるもの:

| 症状 | 対処 |
| --- | --- |
| 押したら設定画面が開いた | APIキーの入力（ChatGPT はサインイン）と、「上記を理解しました」のチェックが必要です |
| 「無料枠のリクエスト制限に達しました」 | 1〜2 分待って「再試行」してください |
| 「ChatGPT のプランの利用枠…に達しました」 | ChatGPT の「設定 → 使用状況」で残りを確認し、回復を待つか、Gemini API に切り替えてください |
| ChatGPT のサインインが「サインイン待ち」のまま | 開いたタブで承認を済ませてください。Codex など、同じ仕組みを使うアプリを先に終了します |
| 翻訳が遅い | 設定画面の「応答速度を診断」で、相手側の遅延かモデルごとの差かを調べられます |
| アイコンに「×」が出た | そのページでは動作できません（ブラウザの設定ページ、ストア、PDF など） |

解決しないときは、このリポジトリの **Issues** でお知らせください。Issues は誰でも読めます。**APIキー・トークン・個人情報・機密情報は、書かないでください。**
