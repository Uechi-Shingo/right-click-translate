日本語に翻訳 – 設定

Gemini API の無料枠、または ChatGPT のプランを使って、右クリックでページや選択範囲を日本語に翻訳します。

はじめに必ずお読みください
  • 翻訳するページの文章（ページ上の文字・タブのタイトル・選択した文字）が、選んだ AI（Google の Gemini、または OpenAI の ChatGPT）に送信されます。翻訳の精度のため、翻訳する部分の直前にある見出し・文章も、訳さない参考として一緒に送ります（短い範囲です）。URL や Cookie、入力欄・コードの中身は送りません。
  • Gemini の無料枠では、送った内容が Google のサービス改善に使われたり、担当者が内容を確認したりする場合があります。メール・社内文書・個人情報や機密情報を含むページには使わないでください。
  • APIキーは「あなた専用の合鍵」です。他の人に教えたり、画面ごと共有したりしないでください。他の人のキーを借りるのも、自分のキーを貸すのもやめましょう。
  • Google 側で支払い方法（請求先アカウント）を登録しないでください。登録しなければ有料プランにはなりません。
  • 送った内容の扱いは、OpenAI の規約と、ご契約の ChatGPT のプランの設定によります。メール・社内文書・個人情報や機密情報を含むページには使わないでください。
  • 翻訳に使った分は、ChatGPT（や Codex）と共通の利用枠から減ります。長いページを何度も翻訳すると、ChatGPT 本体が使えなくなる場合があります。
  • サインイン情報は「あなた専用の合鍵」です。他の人と共有しないでください。共用パソコンでは、使い終わったらサインアウトしてください。
  • 「もう一方の AI に切り替える」をオンにすると、上限・エラーのときに、もう一方の会社（Google または OpenAI）にも、翻訳する文章が送信されます。
使う AI（主に使う方）
ChatGPT のサインイン
新しいタブで OpenAI のサインイン画面が開きます。ログインして承認すると、自動でこの画面に戻ります。パスワードを入力するのは OpenAI の画面だけで、この拡張機能には渡りません。
確認中…
この方法は、OpenAI の公式ドキュメントが、ブラウザ拡張機能での利用に触れていません（許可も禁止も書かれていません）。OpenAI の仕様変更で、使えなくなる可能性があります。

APIキーの取得（無料）

  1. Google AI Studio の APIキーのページを開き、Google アカウントでログインします。
  2. 「APIキーを作成」を押し、表示されたキーを上の欄に貼り付けます。

ChatGPT のサインインについて

  • 「ChatGPT でサインイン」を押すと、サインイン画面のタブが開きます。ログインして、表示される内容を確認のうえ、承認してください。
  • 使える利用枠は、ご契約のプラン（Plus / Pro など）で決まります。ChatGPT の「設定 → 使用状況」で、残りを確認できます。
  • 接続を完全に解除したいときは、この画面の「サインアウト」に加えて、ChatGPT の設定の接続済みアプリからも解除できます。
  • うまくいかないときは、Codex（コマンドライン）など、同じ仕組みでサインイン中のアプリを先に終えてから、もう一度お試しください。

使い方

  • ページ上で右クリック →「このページを日本語に翻訳 / 元に戻す」
  • 文字列を選択して右クリック →「選択範囲を日本語に翻訳」
  • ツールバーの拡張機能アイコンをクリックしても、ページ翻訳の開始・解除ができます。

ご注意

  • 無料枠・プランの利用枠には、回数や量の制限があります。上限に達すると翻訳が止まり、時間を置くと再開できます。
  • 短時間に大量の翻訳が要求された場合は、利用枠を守るため、安全装置が働いて一時停止します。
